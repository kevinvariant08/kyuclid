# Name report: "MathWars"

Task 19, part 1. Checked on **30 October 2026**. Every claim below links to the record or page it comes from. Registers and websites change, so re-check anything before acting on it.

> **This is not legal advice.** It is a desk search by a non-lawyer, done to decide whether a rename is worth considering. Searching a register can show a conflict, but it can't show that a name is safe to use. Before filing a trade mark, buying a domain for real money or launching commercially, get a UK trade mark attorney to run a proper clearance search.

## Recommendation: rename, and do it before launch

**Recommended:** rename now, while the name is in only one HTML file and one repository path. The top pick is **Kyuclid**, and the runner-up is **Belt Theory** (see [alternatives](#eight-alternatives)). Either one keeps the current identity: the kyu belts, the ∴ seal and the type.

**Why not keep MathWars?** Three findings point the same way.

1. **A live US registration covers the same name for the same kind of service.** MATH WARS METHOD, US Reg. No. 7,274,462, has been registered since 16 January 2024 in class 41 for maths mentoring, maths teaching, maths test-prep classes and school-level courses. The register disclaims "MATH" and "METHOD", which leaves **WARS** in the context of maths education as the distinctive part, and that is exactly what MathWars uses. The owner sells it to teachers as a "Math Wars" programme. MathWars's AMC, AIME and USAMO material is aimed at US students too. ([USPTO record](https://tmsearch.uspto.gov/search/search-results/97630728), [owner's site](https://www.collaboratedconsulting.org/), [customer reviews naming the programme](https://www.trustpilot.com/review/collaboratedconsulting.org))
2. **The name already means something else.** "Math wars" is the standard term for the long US argument about how school maths should be taught ([Wikipedia](https://en.wikipedia.org/wiki/Math_wars)). It is still in the news in 2026 ([The 74](https://www.the74million.org/article/math-wars-new-york-wants-to-reform-math-instruction-but-experts-disagree-on-how/), [CRPE, *Navigating the Math Wars*, 2026](https://crpe.org/wp-content/uploads/Navigating-the-Math-Wars-2026.pdf)). People searching for the site will find that debate first, and the name hints at a fight about pedagogy rather than a dojo for problems.
3. **The obvious domains are gone, and the name is crowded.** mathwars.com is registered and appears to be listed for sale. mathwars.org redirects to Mathnasium, a large maths-tutoring franchise. mathwars.io was registered six days before this check. At least five other maths games or web apps use "Math Wars" or a close variant, one of them a 1v1 maths-duel site (details below).

**The case for keeping it, and why it isn't enough.** MathWars is free and hosted on a GitHub Pages sub-path, and CollaboratEd sells teacher training rather than a student problem site. In practice, a complaint today is unlikely. But keeping the name only works while MathWars stays small and non-commercial, and it gets harder to change as accounts, links and social handles build up. The UK register couldn't be checked either (see below), so a "keep" would have no evidence behind it on Kevin's home register.

**Why not "keep with a modifier"?** A modifier such as "MathWars Dojo" or "MathWars by Kevinvariant" keeps "Math Wars", which is the part that conflicts with the registration, and it doesn't fix the search problem. It is the weakest of the three options.

## Eight alternatives

All eight keep the existing identity: the kyu belt ladder, the ∴ seal (∴ means "therefore"), Big Shoulders Display with IBM Plex, and the colours. The two-word names keep the current wordmark layout.

Each name was checked on 30 Oct 2026 for:
- **USPTO:** tmsearch for the name, with spaces and without. The search ranks exact matches first, so "no exact mark" means the name itself didn't appear at the top. Live marks on a single word in the name are noted when they fall in class 9 (software), 28 (games) or 41 (education).
- **Domains:** RDAP for .com and .org, the registry WHOIS for .io and .co.uk.
- **Handles:** GitHub and Bluesky through their APIs.
- **The web:** one search for the exact name.

UK IPO wasn't checked for any of them, for the reason given above.

## Method

- **USPTO:** the official search at https://tmsearch.uspto.gov/, read in a browser. The full records were opened for serials 97630728 and 87189216.
- **Domains:** Verisign RDAP (.com and .net), Public Interest Registry RDAP (.org), whois.nic.io (.io) and whois.nic.uk (.co.uk and .uk), with an HTTP request to see where each live domain points.
- **Handles:** the GitHub REST API (`/users/<name>`), the Bluesky public API (`app.bsky.actor.getProfile`), and a page load for YouTube and Instagram.
- **Web:** a "No uses found" entry means a web search for the exact name, run on 30 Oct 2026, returned nothing that uses it.
- **Products:** web searches for "Math Wars", "MathWars", "Maths Wars" and "Maths War", each combined with app, game, education, UK and trademark.
- **Not done:** UK IPO, WIPO and TMview (blocked by human-verification checks), the X, TikTok and Facebook handles (need a login or wouldn't load), and the Apple App Store listings (opened only as search listings, not page by page).
